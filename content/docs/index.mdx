Aether is S3-compatible object storage written in Rust, for teams that run their
own servers or containers and need object storage for internal applications.
No AWS account or cloud service is involved: "AWS" in these docs only refers to
standard S3 client tools.

A single node works with the AWS SDKs, the AWS CLI, boto3 and rclone. It
supports multipart uploads, server-side copies, per-application access keys,
HTTPS, Prometheus metrics, a Docker image and a web console, and since v2
versioning, lifecycle rules, object tags and encryption (SSE-S3 and SSE-C).

<Callout title="Status">
  The v1 and v2 milestones are complete, but Aether is not yet proven in production. CI
  drives the clients above against a live server and runs 321 of Ceph's
  s3-tests. It is a single node with no replication yet, so back up the data
  directory.
</Callout>

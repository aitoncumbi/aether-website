CI drives the AWS CLI v2, boto3 and rclone against a live server, and runs 321
of Ceph's [s3-tests](https://github.com/ceph/s3-tests).

## Limitations

- **Signature Version 4 only, by default.** boto3 and AWS CLI v1 presign URLs
  with the deprecated SigV2 unless told otherwise; see
  [Connect clients](/docs/connect-clients). `s3.allow_sig_v2 = true` accepts SigV2
  for clients that cannot be changed.
- **Path-style addressing by default** (`http://host:9000/bucket/key`).
  Virtual-hosted style (`http://bucket.s3.example.com/key`) needs a base domain
  in `s3.domains`; see [Connect clients](/docs/connect-clients#virtual-hosted-style).
- **Supported since v2:** [versioning](/docs/versioning),
  [lifecycle rules and object tags](/docs/lifecycle), and
  [encryption](/docs/encryption) with SSE-S3 and SSE-C.
- **Not supported yet:** SSE-KMS; lifecycle transitions (Aether has one storage
  class); object lock; ACLs and bucket policies
  (per-key bucket permissions replace them); browser POST uploads.
  Requests that need these fail with `NotImplemented` rather than being ignored.
- **One node only:** no replication yet, so back up the data directory. See the
  [roadmap](https://github.com/aitoncumbi/Aeather/blob/main/docs/ROADMAP.md) for
  clustering.

---
title: Web console
description: Manage buckets, objects and keys in the browser.
---

Open the admin port in a browser, `http://127.0.0.1:9001/`, and sign in with
the root key or another admin key. The console shows usage and request
activity, creates and deletes buckets, browses, uploads, downloads and deletes
objects, makes presigned share links, and manages keys and their bucket
permissions.

## Reaching it from another machine

The admin port listens on loopback by default. From another machine, either:

- use an SSH tunnel: `ssh -L 9001:127.0.0.1:9001 server`, then open
  `http://127.0.0.1:9001/`, or
- serve the admin API over HTTPS (`tls.admin = true`, see [HTTPS](/docs/https))
  on a reachable address.

## Sessions

Sign-in sessions end on sign-out, after 15 minutes idle (automatic page
refreshes do not count) or 7 days, when the server restarts, and immediately
when the key is disabled or deleted. The browser keeps only a session cookie,
never the secret.

## Share links

Share links are presigned S3 URLs: whoever has one can download the object
until it expires, from the S3 port. They use the host name the console was
opened with. When clients reach the S3 API at another address (a load
balancer, a reverse proxy), set:

```toml title="aether.toml"
[s3]
public_url = "https://s3.example.com"
```

## Bucket settings

A bucket's page shows its [quota](/docs/buckets#quotas), with **Edit** to set or
remove limits, a switch for [versioning](/docs/versioning) with the size of
older versions, and its [CORS rules](/docs/buckets#cors-uploads-from-the-browser)
and [lifecycle rules](/docs/lifecycle), which are set through the S3 API.

In a [versioned](/docs/versioning#in-the-web-console) bucket, an object's
details list its versions to download, restore or delete, and **Deleted
objects** lists deleted keys so they can be restored.

An object's details show its tags and whether it is
[encrypted](/docs/encryption). Objects encrypted with a client's key (SSE-C)
cannot be downloaded or shared from the console, since it does not have the key.

## Notes

- Request charts cover what the server has seen since it started; use the
  [Prometheus metrics](/docs/monitoring) for long-term history.
- `admin.console = false` turns the console off; the admin API is unchanged.
